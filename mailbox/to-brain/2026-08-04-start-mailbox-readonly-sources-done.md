# Мандат 08-04 внедрён

## Изменённые файлы

- `.claude/commands/start.md` — шаг «Sync brain (git pull)» удалён; вместо него шаг 3
  «Скан входящих — два канала»: локальное чтение `from-brain/*.md` как есть (без git-команд
  в чужом репо) + листинг того же пути на GitHub `main` через
  `gh api repos/Valstan/brain_matrica/contents/...?ref=main`. Набор = объединение; при
  расхождении одноимённого письма — свежесть по истории именно этого пути
  (незакоммиченная локальная версия свежее; иначе локальный коммит файла vs последний
  коммит пути через `gh api .../commits?path=...`), порядок не определяется → читаются
  обе версии с явной пометкой конфликта, без перезаписи. Свежесть не переносится между
  письмами/репо.
- `AGENTS.md` — §«Чужие репозитории — только чтение» (запрет fetch/pull/checkout в
  соседях), таблица mailbox и шаги старта переписаны под двухканальную схему, в
  §«Что НЕЛЬЗЯ» добавлен явный запрет синхронизации чужих репо.

## Подтверждения

- Чужие репозитории больше не синхронизируются: ни fetch, ни pull, ни checkout.
- Mailbox читается из двух каналов с правилом свежести по каждому письму.

На `/start` 09.08 старая команда ещё содержала шаг «pull brain» — он был выполнен до

сессию сделана уже по-новому: локальный набор и GitHub `main` совпали письмо-в-письмо,
конфликтов нет. С этого коммита шаг из команды удалён.
